# 07 用户操作手册 — DSH Remote

> 版本：v0.2 · 配套：06-install-run.md · 面向使用手机 App 的最终用户
## 1. 快速开始
1. 确认电脑端 dsh（DeepSeek Harness）正在运行。
2. 手机与电脑连接**同一 WiFi**（或电脑已加入 Tailscale 且手机装有 Tailscale App）。
3. 打开 DSH Remote App：
   - **扫码连接**：对准电脑屏幕上 dsh 设置页「连接移动端设备」的二维码，自动填入地址+口令。
   - **手动输入**：地址 `http://<电脑局域网IP>:3080`（外出用 Tailscale IP） 访问口令（部署者配置的 `authToken`）。
4. 连接成功进入首页，直接发消息派活。
## 2. 界面说明

| 区域 | 功能 |
|---|---|
| 首页 | 欢迎语 + 最近会话 + 底部输入框（模型/权限胶囊）；右上角铃铛进通知 |
| 对话页 | 消息流：你的消息（右）、Harness 回复（左，Markdown 渲染）、token 用量、轮次分隔线；底部输入框发送，状态点显示执行中/等待回答 |
| 会话列表 | 全部会话（标题/时间/工作目录），点按进入；下拉刷新 |
| 通知中心 | 完成✅ 失败❌ 需回答⚠ 三色通知，未读角标，点击跳转会话，全部已读 |
| 设置 | 连接信息、默认 Agent/权限预设、余额、显示工具调用、深色模式、环境诊断、重新配置连接 |

## 3. 常用操作

**发消息/派任务**：首页或对话页底部输入 → 发送。消息注入电脑端正在运行的 agent，立即开始执行；手机实时看到流式回复。
**切换会话**：抽屉 → 会话 → 点按进入。标题与 PC 端实时同步。
**切换工作区**：抽屉 → 工作区（或会话页顶部筛选条）→ 选择目标工作区。会话列表与首页"最近会话"只显示该工作区下的会话；新建会话默认在该工作区目录下创建。
**看更早的消息**：对话页向上滑动——滑到顶部会自动加载更早一页，继续上滑继续加载（微信式，无断页）；已到会话开头会有提示。往上翻后右下角（输入框正上方）会出现灰白色「回到底部」圆钮，点按直接回到最新消息。
**收通知**：agent 完成任务/需要你回答/失败时，App 通知页出现通知；配合推送桥（Server酱/ntfy/Bark）可收手机系统弹窗（需部署者配置 `pushUrls`）。
**删除通知**：通知页**长按**某条可单独删除；右上角垃圾桶 → 批量多选删除或清空全部。仅删除手机 App 里的记录，不影响电脑端。
**审批/回答**：agent 思考途中需要你拍板时，对话页弹出卡片——按选项选择（可多选），或输入你自己的答案后「提交」；工具需要更高权限时弹出「权限请求」，选「允许一次 / 拒绝」。与电脑端同一个待办，任一端回答后两端同时消失；也可点卡片右上角 ✕ 取消（agent 按取消继续）。agent 只是等待你普通回复时（状态点橙色），直接输入消息即可。
**新建会话**：首页「＋ 新建会话」→ 选模式（标准/PTC/极简/创造）→ 可选工作目录（跨盘浏览、可新建文件夹）→ 创建。
**修改默认配置**：设置 → 默认 Agent 预设 / 默认权限预设 → 选择（作用于之后新建的会话，与 PC 端同一写入通道）。
**深色模式**：设置 → 深色模式：跟随系统 / 深色 / 浅色。
**重新配置连接**：设置 → 重新配置连接 → 回到连接页（可重新扫码/输入）。
## 4. 安全须知

- 访问口令是唯一凭据：二维码含口令，请勿截屏转发；怀疑泄露立即在 `cordis.patch.yml` 更换并重启。
- App 仅与电脑直连（局域网/Tailscale），无 TLS —— 只在**自家可信 WiFi** 或 **Tailscale** 下使用；不要把 3080 端口暴露公网。
- 连接信息仅存手机本地，不上传任何第三方。
## 5. 常见问题（FAQ）
**Q1 连接失败/超时**
- 电脑端 dsh 是否运行？`webserver` 是否配置 `host: 0.0.0.0`（否则只允许本机）？
- 手机与电脑是否同一网络？口令是否正确（改过需重启桌面端）？
- Windows 防火墙若拦截 3080，放行 `node`/`DeepSeek Harness`。
**Q2 扫码没反应**
- App 用自带「扫码连接」按钮（系统相机会跳浏览器打开网页）；二维码随口令变更而更新（改口令需重启桌面端）。
**Q3 发消息没反应**
- agent 正在处理上一轮时新消息会**排队**（App 有提示）；等上一轮完成。
- 状态点：绿色=执行中，橙色=等待你回答（直接回复）。
**Q4 收不到系统通知**
- 需部署者配置 `pushUrls`（Server酱/ntfy/Bark）；检查手机通知权限。
**Q5 看不到实时回复**
- SSE 断线自动重连（指数退避），恢复后自动补拉历史；检查网络。
**Q6 新建会话在 PC 端显示"未分组"**
- 所选目录不在任何已注册工作区（或其子目录）；在工作区子目录下会自动归属。
**Q7 agent 问问题/要权限时，手机不弹卡片**
- 确认你在**该会话的对话页**（弹窗是会话内的，别处只有通知中心「需要你回答」条目，点进去即见弹窗）。
- 电脑端 dsh 是否为最新版并已**重启**（弹窗桥随插件加载）？App 设置 → 环境诊断：`respondBridge`/`frameBridge` 应为 ✅（否则见 docs/09-compatibility.md）。
- 若电脑上也没有弹窗：可能是该会话审批策略为「从不询问」，或你的 Harness 已配置自动答题/自动审批（此时不弹窗是正常行为）。
**Q8 其他品牌手机能用吗 / 有苹果版吗**
- Android 7.0+ 均可（渲染自动回退，详见 docs/09-compatibility.md §3）；苹果端尚未开发（§4）。
**Q9 换手机/重装后要重新连接吗**
- 要：连接信息只存手机本地，换机后用二维码重新扫一次即可（口令未变则无需改电脑端）。
